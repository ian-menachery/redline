## Reproducibility

This file is generated by `python -m redline.eval.report` from the persisted `eval_runs` table. Regenerating the numbers **requires network access to EDGAR and an LLM API key** (extraction + LLM-judge grading), and LLM output is not bitwise-deterministic — `--fresh` guarantees independence from prior DB state, not identical bytes.

**Graded scorecard** — isolated run, independent of any prior state:

```
python -m redline.eval.harness --all --db-path data/eval_run.db --fresh
python -m redline.eval.report  --db-path data/eval_run.db   # the graded section
```

**8-K guidance panel** — selected by a mechanical rule (Rule R) over persisted DB state (a pure, deterministic read, no network at selection time), then extracted and scored against the operational database (`data/redline.db`, the default). This committed file is that database's report:

```
python scripts/backfill_8ks.py --months 15   # live EDGAR, no LLM
python -m redline.valuation.guidance --once   # extraction (needs an LLM key)
python -m redline.valuation.guidance_eval     # precision/recall on scope=total
python -m redline.eval.report                 # regenerate this file
```

The two blocks target different databases (the isolated `data/eval_run.db` vs the operational `data/redline.db`) — run whichever section you want to reproduce.
